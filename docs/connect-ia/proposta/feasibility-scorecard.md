# Incubator feasibility scorecard — Captei vs MucoCreate

Síntese da análise estruturada (Gemini + docs internos) para decisão de pivot Connect IA.

**Decisão (15/09/2026):** pivot para **Captei** (versão omnichannel).

---

## Strategic evaluation matrix

| Dimensão | MucoCreate | Captei | Vencedor |
|----------|------------|--------|----------|
| Urgência de mercado | Média — workflow, não P&L | Alta — captação = receita direta | **Captei** |
| Previsibilidade receita | Baixa — compra única $49–79 | Alta — MRR R$99–999/mês | **Captei** |
| Defensibilidade técnica | Alta — RT audio + ONNX | Média-alta — compliance + workflow + dados consent | MucoCreate (tech puro) |
| Custo GTM | Baixo — global/plugin stores | Médio — vendas locais + onboarding | MucoCreate |
| Prova de dor (pré-MVP) | Fraca — subjetiva até ML funcionar | Forte — corretores disponíveis | **Captei** |
| Fit Connect IA (IA 40%) | Muito forte | Forte (omnichannel agent) | Empate técnico |
| Fit Connect IA (mercado) | Médio | Muito forte | **Captei** |

## Captei — unit economics (framework)

| Métrica | Hipótese inicial | Notas |
|---------|------------------|-------|
| **Pricing** | R$ 149/mês starter; R$ 399 agência | Validar no piloto |
| **Churn mensal** | 3–5% (B2B SMB) | Depende de integração CRM |
| **CAC** | R$ 800–1.500 (rede local + CRECI) | Founder network reduz |
| **LTV (24 mo)** | R$ 3.600–9.600 | 24 × ARPU × (1-churn) |
| **LTV:CAC** | Alvo > 3:1 | Atingível com 1 gestora referência |
